The widget was declared `multi: false`, but the append-only log doesn't care; it just records every action. The renderer (and I) treat "your answer" as the latest event for a given `choices_id`. If the kernel were storing state in a database row, your earlier picks would be gone. Here they're still on disk, and a "history" view would surface all four clicks as a little decision trail.
