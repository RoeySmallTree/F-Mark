## Route structure

F-Mark is a **single-route SPA** plus one standalone page. "Screens" are panes, panels, modals, and
popovers — not routes. Router truth: `renderer/src/main.tsx` branches on
`location.pathname.startsWith("/file-tree")`; everything else renders `App.tsx`. The kernel's
`routes/static.ts` catch-all serves `index.html` for any non-API path, so there is no 404 surface.

| Route                      | Renders                                                                        |
| -------------------------- | ------------------------------------------------------------------------------ |
| `/`                        | `App.tsx` → `AppShell` (TopBar + LeftPanel + dock areas + RightPanel + modals) |
| `/file-tree` (`?path_id=`) | `pages/FileTreePage.tsx`, state-isolated via its own storage namespace         |
