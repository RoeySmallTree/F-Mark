# Node 20 test baseline — CORRECTED 2026-08-22

# The previous version of this file listed 17 renderer failures across 6 files
# as the "known baseline". That was wrong, and wrong in a way worth recording:
# it was measured ON the redesign branch and never compared against
# `origin/main`. Diffing by test name against origin/main (0b53c36) showed all
# 17 were REGRESSIONS introduced by the Aurora work, not inherited noise. A
# baseline taken from the branch under test can only ever confirm itself.
#
# All 17, plus 10 equivalent kernel regressions in tests/routes/theme.test.ts,
# are fixed as of this commit. Root causes were:
#   - themes went 17 -> 3 (Day/Night/High contrast); tests still named ember,
#     dracula, nord, terminal, and asserted "Light" where the label is now "Day"
#   - dock layout went v4 -> v5, which empties the toolbar into the right dock,
#     so `search` moved and every hardcoded right-dock array was one short
#   - ViewModeToggle moved from TopBar to LedgerHeader
#   - packages/shared/src/themeTokens.ts had drifted from tokens.css: it still
#     carried pre-final Aurora values, so the kernel served agents the wrong
#     hex codes via GET /theme. It also never picked up the 9 Aurora tokens
#     (paper*, rule*, ledger*, alarm), which are now tracked.
