**Why an append-only app needs this isolation:** F-Mark never deletes. A revision is a new event with
`supersedes`; a deletion is a prose tombstone. Anything this sweep creates or tombstones in a real
session would be permanent, so the sweep only ever runs against a throwaway root.

## Route structure

Single-route SPA plus one standalone page. Router truth: `renderer/src/main.tsx` branches on
`location.pathname.startsWith("/file-tree")`. The kernel's `routes/static.ts` catch-all serves
`index.html` for any non-API path, so **there is no 404 surface**. "Screens" are panes, panels,
modals and popovers — not routes.

| Route                      | Renders                                                                        |
| -------------------------- | ------------------------------------------------------------------------------ |
| `/`                        | `App.tsx` → `AppShell` (TopBar + LeftPanel + dock areas + RightPanel + modals) |
| `/file-tree` (`?path_id=`) | `pages/FileTreePage.tsx`, state-isolated via its own storage namespace         |

Baseline at rest, measured on load: 34 buttons · 18 tabs · 10 inputs · 46 interactive nodes total,
before any pane, modal or popover is opened.
