- Context usage remains unknown for all runtimes in this workspace. Do not show invented token usage in UI; Phase 13 deliberately returns `Unknown`.
- Browser UI flows are now hot-tested through the setup, agents, and targeting phases. Continue requiring production-renderer hot gates for future UI phases.
- Native runtime fork/branch commands are not yet enabled. Phase 18 proved F-Mark-owned fork UX and real vendor MCP writes after fork; Claude/Codex native fork commands are visible in CLI help but remain `verified:false` until a managed-pane slash-command smoke passes. Gemini has no native fork command in the observed CLI.
- Gibbs' independent hot-test found repeated Node OOM when its harness forwarded stubbed `fetch` into `app.inject`. Direct route injection and stubbed `runAutoStream` passed, and the local live-kernel manual test passed, so this is logged as a hot-test harness discrepancy, not a confirmed kernel bug.
